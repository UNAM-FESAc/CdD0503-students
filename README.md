## Bienvenido(a)

Bienvenido(a) al repositorio oficial del curso **Métodos Matemáticos Computacionales para Ciencia de Datos (CdD 0503)**.

Este repositorio contiene el material oficial del curso **Métodos Matemáticos Computacionales para Ciencia de Datos (CdD0503)** impartido en la **Facultad de Estudios Superiores Acatlán de la Universidad Nacional Autónoma de México**.

El objetivo del curso es desarrollar fundamentos sólidos en análisis numérico, álgebra lineal computacional y métodos matemáticos aplicados a Ciencia de Datos mediante laboratorios interactivos, programación científica y evaluación automática.

En este repositorio encontrará:

- 📚 Laboratorios interactivos en Jupyter Notebook.
- 💻 Talleres de programación en Python.
- 📈 Ejercicios de análisis numérico y ciencia de datos.
- 📝 Material complementario del curso.
- 🎓 Evaluaciones automáticas mediante **nbgrader**.
- 🌐 Recursos adicionales y bibliografía.

Se recomienda trabajar cada laboratorio en el orden establecido y documentar claramente el desarrollo de cada ejercicio.



---
## Objetivos de aprendizaje

Al finalizar este curso, el estudiante será capaz de:

- Resolver problemas de álgebra lineal mediante métodos numéricos.
- Implementar algoritmos científicos utilizando Python.
- Analizar estabilidad, convergencia y complejidad computacional.
- Aplicar técnicas de análisis numérico en problemas de Ciencia de Datos.
- Utilizar bibliotecas científicas como NumPy, SciPy, Matplotlib y Pandas.
- Documentar y reproducir experimentos computacionales mediante Jupyter Notebook.

## Flujo de trabajo

Cada laboratorio sigue la siguiente metodología:

1. Leer la teoría.
2. Analizar el algoritmo.
3. Implementar el código.
4. Ejecutar los experimentos.
5. Validar la solución.
6. Entregar el notebook.
